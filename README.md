# Rick-and-Morty


A responsive website dedicated to the animated series **Rick and Morty**. Explore characters and episodes, search for your favorites, and discover information from the Rick and Morty API.

 # About the Project

Rick and Morty is a responsive website where users can explore characters and episodes from the animated series.

The website fetches data from the Rick and Morty API and displays it in an interactive and user-friendly interface.

 # Features

- Browse characters and episodes.
- Search for characters and episodes.
- Filter characters by status, species, type, and gender.
- Sort and explore available information.
- Load more characters and episodes using pagination.
- View detailed information about episodes.
- Responsive design for desktop, tablet, and mobile devices.

# Technologies

HTML5 — website structure.
SCSS (Sass) — styling and responsive layouts.
JavaScript  — functionality and API integration.
Parcel — project bundler.
Rick and Morty API — fetching characters, episodes, and other data.
Figma — design reference.
